Start

The portal looks like infrastructure you already trust

The portal follows the conventions of GitHub settings, the Tailscale and Cloudflare consoles, and Grafana. A physicist or an operator should recognise every control without learning anything. The design's job is to make the state of someone's access obvious and to show the one thing to do next.

Four rules everything else follows from

  • Containers recede, content leads. A box, a rule or a header never competes with the data inside it. Borders are 1px and pale; fills are rare.
  • Colour means something or it is absent. Neutrals are untinted greys. The accent marks the main action and the current location; it is ink unless a facility opts into its own colour. Status colours mark status and nothing else.
  • The facility accent is never a message. Banners and alerts always use the fixed status colours, so a maroon or yellow facility cannot be mistaken for an error or a warning.
  • One loud thing per page. At most one banner, at most one primary button. If nothing is wrong, the page is quiet.

Every table, token and name on this page is example data. Use the controls above to change the facility accent and the theme; every example responds.

Design tokens

A token is a named design decision. Code refers to the name, never to the raw value, so a decision is changed in one place. The portal has three layers, the same structure Uber's Base uses.

LayerWhat it isExampleWho may use it
1. PrimitiveA raw value with a neutral name.--grey-200: #e0e0e0Only the semantic layer.
2. SemanticA role. Changes between light and dark.--border: var(--grey-200)Every component and page.
3. ComponentA class that combines semantic tokens..btn.primaryPages.
border: 1px solid var(--border);
padding: var(--space-16);
font-size: var(--text-14);

Do use a semantic token for every colour, size, radius and duration.

border: 1px solid #1e2a3d;
padding: 14px;
font-size: 9px;

Don't write raw values in a component. The current portal has 16 font sizes and 5 radii because of this.

Enforcement: a lint rule rejects hex colours, pixel font sizes and off-scale spacing in portal/src. Without it the written system and the shipped portal drift apart again.

Visual styles

Colour

Three groups with separate jobs. Neutrals build the page. The accent marks action and location: ink by default, or a colour the facility opts into. Status colours are fixed for every deployment and carry meaning.

Neutrals

Facility accent

The default is a neutral monochrome theme: the accent is ink, black in light mode and white in dark. The portal does not give a facility an identity it has not chosen. A deployment may opt in by setting one colour; the portal derives the rest, so any colour is safe:

  • --accent appears only as a fill (primary button, checked control) or a 3px indicator (current nav item). It is never a text colour, so a pale facility colour cannot produce unreadable links.
  • --on-accent is computed: white if it reaches 4.5:1 on the accent, otherwise near-black.
  • In dark mode a dark accent is lightened until it reaches 3:1 against the page, unless the deployment supplies its own dark-mode value.

Expression

Motion

Motion explains a change: something appeared, moved or finished. Nothing moves for atmosphere on working pages.

TokenValueUse
--time-fast100msHover and press colour changes.
--time-base200msMenus, tooltips, disclosure open and close.
--time-slow300msDialog enter. Banner appearing after an action.
--easecubic-bezier(0.2, 0, 0, 1)Everything. Starts fast, settles.
  • Tables, rows and page content do not animate on load.
  • Only opacity and transform are animated.
  • With reduced motion requested, every transition is instant.
  • Two named exceptions are kept on purpose: the particle-track canvas behind the Overview header, and the gateway diagram on the landing page. Both stop when reduced motion is requested, and neither sits behind text a person needs to read.

Expression

Icons

An icon repeats a label; it does not replace one. One set, Lucide, at one size.

  • Icons are inline SVG, so they inherit text colour and need no network request or icon font.
  • They come from the @lucide/vue and @lucide/astro packages, pinned in package.json. The lockfile records the version and the ISC licence; markup is not pasted by hand, so an icon can always be traced and updated.
  • 16px beside 14px text, 20px in the large button. Lucide's default stroke; no per-icon weights or colours.
  • Decorative icons are aria-hidden. An icon-only button has an accessible name.

Every signed-in page has the same four parts in the same order: title with the one primary action, the banner slot, then sections. A person who has seen one page knows where to look on all of them.
